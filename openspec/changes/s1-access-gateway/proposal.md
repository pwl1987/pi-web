# 提案：S1 本地访问令牌网关 + 会话归属校验（change s1-access-gateway）

## 背景 / 问题

pi-web 是一个**本地单用户**的 AI coding agent Web UI。当前存在 **S1（#1 阻塞风险）**：
无 `app/middleware.ts`、无用户会话体系，任何能触达回环端口（乃至非回环绑定时局域网）的进程都能
**无差别读写所有会话、触发命令执行、窃取 API 密钥**。`bin/pi-web.js` 已默认回环绑定并在非回环时
打印「无认证」警告——维护者已知此缺口，但始终未落地网关。

依赖 S1 缺失才可利用的衍生风险（评审 Top 10 中 #2/#3/#4/#5/#10）包括：

- 文件新-1 `files/[...path]` sessionReference 旁路任意路径读取（`/etc/shadow`）
- S3 `mcp-config/test` 用户可控命令任意执行
- S4 / 配置新-2 任意 npm 包安装
- S5 / 配置新-6 扩展 symlink 加载不可信模块
- L10 会话/文件无归属校验导致越权导出

**本 change 只解决网关层（S1 认证 + L10 归属校验的边界收敛）**。mcp-config/test、包安装、扩展
symlink 等**端点内部**的加固（S3/S4/S5）仍属各自独立 change，不在本提案范围，但本提案的归属校验
会作为它们的统一前置防线。

## 目标

1. 引入**本地访问令牌**体系：服务启动生成一次性令牌，明文仅交付给启动终端 + 自动打开的浏览器，
   服务端只存哈希，杜绝「任何人连上即可取令牌」的引导端点。
2. 新增 `app/middleware.ts`（Edge runtime）对所有 `/api/*` 请求做 **Bearer / cookie / `?token=`**
   三源校验，与 `PI_WEB_ACCESS_TOKEN_HASH` 环境哈希做定时安全比较。
3. 新增**降级开关** `PI_WEB_DISABLE_AUTH=1`：默认关闭；启用后彻底跳过网关（救命绳，防自锁门外）。
4. 将 **L10 归属校验**并入敏感资源路由入口，确保会话/文件落在 `~/.pi/agent/sessions` 与 cwd 允许
   列表内（与第 2 轮对 `sessionReference` 的受信根收敛互补）。
5. dev（`next dev`）与生产（`bin/pi-web.js start`）行为**强制一致**：未配置令牌时**不**自动开放，
   必须显式 `PI_WEB_DISABLE_AUTH=1` 才降级（避免 CSRF dev 失效的同款盲区）。

## 非目标（明确排除）

- 多用户 / owner 字段 / OAuth 登录（单用户本地工具，过度设计）。
- S3/S4/S5 等端点**内部**的命令/包/模块白名单加固（各自独立 change）。
- 远程访问的安全基线（见 `docs/remote-access.zh-CN.md`，本 change 只保证「拿到令牌才放行」）。

## 决策点（已按最保险取向固化，需人工最终确认）

| #   | 决策        | 取值                                               | 备注                                    |
| --- | ----------- | -------------------------------------------------- | --------------------------------------- |
| D1  | 令牌交付    | 终端打印 + 自动打开 `?token=`                      | 不新增取令牌引导端点                    |
| D2  | 开发模式    | **强制令牌**（dev 未配置则默认生成并注入，不开放） | 与现状 CSRF dev 放开相悖，取保守侧      |
| D3  | 开放端点    | 仅静态资源 + 无状态 `/api/health`（不含数据）      | 最小暴露面                              |
| D4  | 归属粒度    | 单用户 → `agentDir`/cwd 允许列表                   | 不引入多用户                            |
| D5  | 与 S2 同 PR | **分 PR**                                          | S2(CSRF 默认开) 独立先合，S1 单独可回滚 |

## 验收

- 启动后终端打印明文令牌；自动打开的浏览器 URL 带 `?token=`，首屏存入 `localStorage` 并抹除 URL。
- 另开隐身窗口（无令牌）访问任意 `/api/*` 返回 401；错误/缺失 `?token=` 亦 401。
- `/api/health` 无令牌可 200（仅返回 `{ok:true}`，无数据）。
- `PI_WEB_DISABLE_AUTH=1` 时整站开放（与令牌无关），用于降级救急。
- `sessions/[id]` / `files/[...path]` 越权访问（资源落于受信根外）返回 403/404。
- `npm run ci`（format+lint+type-check+test:node+test:coverage）全绿。
